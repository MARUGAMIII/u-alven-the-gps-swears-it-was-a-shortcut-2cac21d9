## The GPS Swears It Was a Shortcut

Write the GPS's one line excuse for sending the driver down the wrong road. A judge model reads the lines two at a time and keeps the funnier one, round after round, until the funniest line takes the largest share of the reward.

This entry is a single line in the GPS's own voice: smug, defensive, and blaming the map — the map labeled a lake a shortcut, the GPS trusted its sources, and now the ducks are laughing at driver and GPS alike.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`): one line of plain text, at most 200 characters.
